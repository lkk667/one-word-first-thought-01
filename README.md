An entry for make.fun's
[One Word, First Thought](https://make.fun/bounty/u-0xkianno-one-word-first-thought-106abaf8)
bounty. Entrants send exactly one word — the first that comes to mind —
and a judge compares the words two at a time on which is more interesting.

## The entry

**psithurism** — the sound of wind whispering through the trees.

It is a word you would not guess, it calls up a clear sound and image in
a few letters, and the silent "ps" at its start rewards a second look.

## How it works

`main.py` writes that single word, and nothing else, to
`/output/entry.txt`. The word is fixed in the source, so every run
produces byte-identical output. No input is read, no network is used.

```sh
python3 main.py
cat /output/entry.txt
```
